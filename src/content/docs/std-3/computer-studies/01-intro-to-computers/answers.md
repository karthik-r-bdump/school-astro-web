## Section B: Short Answer Solutions
1. **Question**: What is a computer:
   - **Answer**: An electronic machine that accepts input data, processes it at high speed, and gives meaningful output results.
2. **Question**: IPO cycle & daily example:
   - **Answer**: Input $\rightarrow$ Process $\rightarrow$ Output. Example: Dirty clothes (Input) $\rightarrow$ Washing in washing machine (Process) $\rightarrow$ Clean clothes (Output).
3. **Question**: 2 Input & 2 Output devices:
   - Input: Keyboard, Mouse.
   - Output: Monitor, Printer.
4. **Question**: Why CPU is brain:
   - **Answer**: Because it controls all operations of the computer and performs all calculations and decision-making.
5. **Question**: Human vs Computer:
   - Computers work at lightning speed without errors or tiredness; Humans have feelings, can think independently, but get tired and make mistakes.
