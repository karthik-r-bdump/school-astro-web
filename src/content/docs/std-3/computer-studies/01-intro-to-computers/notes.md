## 📖 Chapter Notes & Simple Explanations
### 1. What is a Computer?
A computer is an **electronic device** that takes raw facts and figures (**data**), works on it (**processes** it), and gives meaningful results (**information**).

### 2. The IPO Cycle (Input - Process - Output)
Every task on a computer follows this three-step cycle:
$$\text{INPUT} \xrightarrow{\text{Keyboard / Mouse}} \text{PROCESS} \xrightarrow{\text{CPU}} \text{OUTPUT} \xrightarrow{\text{Monitor / Printer}}$$

- **Real-Life Examples of IPO**:
  - *Sharpening a pencil*: Blunt pencil (Input) $\rightarrow$ Sharpening in sharpener (Process) $\rightarrow$ Sharp pointed pencil (Output).
  - *Making mango shake*: Mango slices, milk, sugar (Input) $\rightarrow$ Blending in mixer (Process) $\rightarrow$ Mango shake (Output).
  - *Adding numbers*: Typing $5 + 3$ (Input) $\rightarrow$ CPU computes $5 + 3 = 8$ (Process) $\rightarrow$ Displays $8$ on monitor (Output).

### 3. Main Parts of a Computer
- **Keyboard**: Input device with alphabet, number, and special function keys.
- **Mouse**: Pointing input device used to select icons and draw pictures.
- **CPU (Central Processing Unit)**: Processing device inside the CPU cabinet (the brain of the computer).
- **Monitor (VDU)**: Output screen showing what the computer is doing.
- **Printer**: Output device that prints results on paper (hard copy).
