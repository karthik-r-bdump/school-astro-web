## Section A: Fill in the Blanks / Multiple Choice
1. Write the place value of the underlined digit: $5\underline{6}82$.
2. Write in expanded form: $7409$.
3. What is the successor of $3999$?
4. What is the predecessor of $5000$?
5. Fill in the blank with $>$, $<$, or $=$: $6045$ ______ $6405$.

---

## Section B: Short Questions
1. Write the number names in words:
   - (a) $4078$
   - (b) $9502$
2. Write the standard numeral for:
   - (a) $6000 + 300 + 40 + 8$
   - (b) $8000 + 50 + 2$
3. Arrange the following numbers in Ascending order:
   - $3450, 3540, 3054, 3405$
4. Form the greatest and smallest 4-digit numbers using the digits $5, 0, 8, 3$ without repeating digits.
5. Find the difference between the place value and face value of 7 in $6742$.

## Section C: Problem Solving / Descriptive
1. Answer the following:
   - (a) Write all the odd numbers between $2450$ and $2460$.
   - (b) Write all the even numbers between $5100$ and $5110$.
   - (c) A library has $4580$ English books and $4508$ Science books. Which subject has more books and by how many?
