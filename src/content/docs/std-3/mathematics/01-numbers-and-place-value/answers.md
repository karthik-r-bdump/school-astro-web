## Section A: Objective Solutions
1. **Question**: Place value of 6 in $5682$:
   - **Answer**: **600** (or 6 hundreds)
2. **Question**: Expanded form of $7409$:
   - **Answer**: **$7000 + 400 + 9$**
3. **Question**: Successor of $3999$:
   - **Answer**: **4000** ($3999 + 1$)
4. **Question**: Predecessor of $5000$:
   - **Answer**: **4999** ($5000 - 1$)
5. **Question**: $6045$ and $6405$:
   - **Answer**: $6045 < 6405$

## Section B: Short Answer Solutions
1. **Question**: Number names:
   - (a) $4078$: Four thousand seventy-eight.
   - (b) $9502$: Nine thousand five hundred two.
2. **Question**: Standard numeral:
   - (a) $6000 + 300 + 40 + 8 = \mathbf{6348}$
   - (b) $8000 + 50 + 2 = \mathbf{8052}$
3. **Question**: Ascending order:
   - **$3054 < 3405 < 3450 < 3540$**
4. **Question**: Digits $5, 0, 8, 3$:
   - Greatest: **8530**
   - Smallest: **3058** (Note: 0 cannot be the leading digit).
5. **Question**: Place value vs face value of 7 in $6742$:
   - Place value $= 700$; Face value $= 7$.
   - Difference $= 700 - 7 = \mathbf{693}$.
