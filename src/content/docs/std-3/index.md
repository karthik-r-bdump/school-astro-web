# Standard 3 (Class 3) ICSE Curriculum

Welcome to the Class 3 ICSE Curriculum Portal! Class 3 is a crucial foundational year where students develop confident reading, creative writing, multi-digit arithmetic, scientific inquiry, and environmental awareness.
