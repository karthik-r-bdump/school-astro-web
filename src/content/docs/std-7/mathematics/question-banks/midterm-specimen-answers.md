## Section A (40 Marks)

### Question 1 Solutions [10 Marks]
- (a) **$(-125) \times 48 \times (-8)$** [3 Marks]:
  - Regrouping: $[(-125) \times (-8)] \times 48 = 1000 \times 48 = 48000$. [3 Marks]
- (b) **$\frac{3}{4} + \frac{5}{6} - \frac{7}{12}$** [3 Marks]:
  - LCM of $4, 6, 12 = 12$.
  - $\frac{9 + 10 - 7}{12} = \frac{12}{12} = 1$. [3 Marks]
- (c) **$2^{x+3} = 64$** [4 Marks]:
  - $64 = 2^6$. Therefore, $2^{x+3} = 2^6$. [2 Marks]
  - Equating powers: $x + 3 = 6 \Rightarrow x = 3$. [2 Marks]

### Question 2 Solutions [10 Marks]
- (a) **Standard Form** [4 Marks]:
  - (i) $405,000,000 = 4.05 \times 10^8$. [2 Marks]
  - (ii) $0.000035 = 3.5 \times 10^{-5}$. [2 Marks]
- (b) **Sets $A$ and $B$** [4 Marks]:
  - $A = \{1, 2, 3, 4, 6, 12\}$, $B = \{1, 2, 3, 6, 9, 18\}$.
  - (i) $A \cup B = \{1, 2, 3, 4, 6, 9, 12, 18\}$. [2 Marks]
  - (ii) $A \cap B = \{1, 2, 3, 6\}$. [2 Marks]
- (c) **Subtraction** [2 Marks]:
  - $(7a - 2b - 3c) - (3a - 5b + 7c) = 7a - 2b - 3c - 3a + 5b - 7c = 4a + 3b - 10c$. [2 Marks]

### Question 3 Solutions [10 Marks]
- (a) **Multiply $(2x - 3)(3x + 5)$** [4 Marks]:
  - $6x^2 + 10x - 9x - 15 = 6x^2 + x - 15$. [2 Marks]
  - When $x = -1$: $6(-1)^2 + (-1) - 15 = 6(1) - 1 - 15 = 6 - 16 = -10$. [2 Marks]
- (b) **$\triangle ABC$ angles** [3 Marks]:
  - $\angle C = 180^\circ - (50^\circ + 70^\circ) = 180^\circ - 120^\circ = 60^\circ$. [2 Marks]
  - Since all angles $< 90^\circ$, it is an **acute-angled triangle**. [1 Mark]
- (c) **Consecutive integers** [3 Marks]:
  - Let integers be $x, x+1, x+2$.
  - $3x + 3 = 81 \Rightarrow 3x = 78 \Rightarrow x = 26$.
  - Integers are **26, 27, 28**. [3 Marks]

### Question 4 Solutions [10 Marks]
- (a) **$3(x - 2) + 4(2x + 1) = 31$** [3 Marks]:
  - $3x - 6 + 8x + 4 = 31 \Rightarrow 11x - 2 = 31 \Rightarrow 11x = 33 \Rightarrow x = 3$. [3 Marks]
- (b) **Ratio $2:3:5$** [3 Marks]:
  - $2x + 3x + 5x = 180^\circ \Rightarrow 10x = 180^\circ \Rightarrow x = 18^\circ$.
  - Angles: $2(18) = 36^\circ$, $3(18) = 54^\circ$, $5(18) = 90^\circ$. [3 Marks]
- (c) **Exponent simplification** [4 Marks]:
  - $\frac{2^3 \times 3^4 \times 2^2}{3^1 \times 2^5} = \frac{2^5 \times 3^4}{2^5 \times 3^1} = 2^{5-5} \times 3^{4-1} = 2^0 \times 3^3 = 1 \times 27 = 27$. [4 Marks]

## Section B (40 Marks)

### Question 5 Solutions [10 Marks]
- (a) **Submarine depth** [3 Marks]:
  - Initial: $-800\,\text{m}$. Ascend: $+250\,\text{m} \rightarrow -550\,\text{m}$. Dive: $-120\,\text{m} \rightarrow -670\,\text{m}$.
  - New position: **$670\,\text{m}$ below sea level** (or $-670\,\text{m}$). [3 Marks]
- (b) **Rational numbers between $1/3$ and $1/2$** [4 Marks]:
  - Express with common denominator $24$: $\frac{1}{3} = \frac{8}{24}$, $\frac{1}{2} = \frac{12}{24}$.
  - Three rational numbers: $\frac{9}{24}, \frac{10}{24}, \frac{11}{24}$ (or $\frac{3}{8}, \frac{5}{12}, \frac{11}{24}$). [4 Marks]
- (c) **Decimals** [3 Marks]:
  - $4.5 \times 0.25 = 1.125$.
  - $1.25 \div 0.5 = 2.5$.
  - $1.125 - 2.5 = -1.375$. [3 Marks]

### Question 6 Solutions [10 Marks]
- (a) **De Morgan's Laws Verification** [6 Marks]:
  - (i) $P' = U - P = \{1, 4, 6, 8, 9, 10\}$. [2 Marks]
  - (ii) $P \cup Q = \{1, 2, 3, 5, 7, 9\} \Rightarrow (P \cup Q)' = \{4, 6, 8, 10\}$.
    - $Q' = \{2, 4, 6, 8, 10\} \Rightarrow P' \cap Q' = \{4, 6, 8, 10\}$.
    - Since LHS = RHS, verified. [4 Marks]
- (b) **Polynomial addition & subtraction** [4 Marks]:
  - Sum: $(4x^2 - 3x + 7) + (2x^2 + 5x - 8) = 6x^2 + 2x - 1$. [2 Marks]
  - Subtraction: $(6x^2 + 2x - 1) - (3x^2 - x + 4) = 6x^2 + 2x - 1 - 3x^2 + x - 4 = 3x^2 + 3x - 5$. [2 Marks]

### Question 7 Solutions [10 Marks]
- (a) **Exterior Angle Problem** [4 Marks]:
  - Exterior angle $=$ sum of interior opposite angles.
  - $115^\circ = 35^\circ + x \Rightarrow x = 115^\circ - 35^\circ = 80^\circ$. [2 Marks]
  - Third angle $= 180^\circ - 115^\circ = 65^\circ$ (linear pair). [2 Marks]
- (b) **Congruence Criteria** [3 Marks]:
  - (i) **SSS** (Side-Side-Side) [1 Mark]
  - (ii) **ASA** (Angle-Side-Angle) [1 Mark]
  - (iii) **RHS** (Right angle-Hypotenuse-Side) [1 Mark]
- (c) **Pythagoras Theorem Rectangle** [3 Marks]:
  - In right $\triangle$, $d^2 = l^2 + b^2 \Rightarrow 17^2 = 15^2 + b^2 \Rightarrow 289 = 225 + b^2 \Rightarrow b^2 = 64 \Rightarrow b = 8\,\text{cm}$. [2 Marks]
  - Perimeter $= 2(l + b) = 2(15 + 8) = 2(23) = 46\,\text{cm}$. [1 Mark]
