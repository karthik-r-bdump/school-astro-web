# Chapter 1: Integers

## 🎯 Syllabus Scope & Objectives
- Definition: Set of whole numbers and negative natural numbers $\mathbb{Z} = \{..., -3, -2, -1, 0, 1, 2, 3, ...\}$.
- Properties of Addition & Subtraction: Closure, Commutative ($a + b = b + a$), Associative ($a + (b + c) = (a + b) + c$), Additive Identity ($a + 0 = a$), Additive Inverse ($a + (-a) = 0$).
- Multiplication Rules: $(+) \times (+) = (+)$, $(-) \times (-) = (+)$, $(+) \times (-) = (-)$, $(-) \times (+) = (-)$.
- Distributive Property of Multiplication over Addition: $a \times (b + c) = (a \times b) + (a \times c)$.
- Division of Integers and BODMAS / PEMDAS rule.

---

## 📖 Key Concepts & Detailed Notes
### 1. Operations on Integers
- **Addition**:
  - Same signs: Add absolute values and assign the common sign. Example: $(-7) + (-8) = -15$.
  - Different signs: Subtract the smaller absolute value from the larger and assign the sign of the larger. Example: $(-15) + 9 = -6$.
- **Multiplication**:
  - Product of an even number of negative integers is **positive**. Example: $(-2) \times (-3) \times (-4) \times (-5) = +120$.
  - Product of an odd number of negative integers is **negative**. Example: $(-2) \times (-3) \times (-4) = -24$.
- **Division**:
  - $a \div 0$ is **undefined**.
  - $0 \div a = 0$ (where $a \neq 0$).

### 2. BODMAS Rule
Order of operations:
1. **B**rackets: Bar/Vinculum $\overline{a-b}$, then Round $( )$, then Curly $\{ \}$, then Square $[ ]$.
2. **O**f (multiplication precedence)
3. **D**ivision and **M**ultiplication (left to right)
4. **A**ddition and **S**ubtraction (left to right)
