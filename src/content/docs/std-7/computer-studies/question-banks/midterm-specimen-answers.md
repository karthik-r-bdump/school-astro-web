## Section A Solutions [40 Marks]
1. MCQs: 1-Hardware, 2-ROM, 3-8 bits, 4-Linux, 5-Trackball, 6-UPS, 7-GUI, 8-Nibble, 9-RAM, 10-GHz. [10 Marks]
2. Fill in blanks: 1-Motherboard, 2-CPU, 3-Volatile, 4-Plotter, 5-Command. [10 Marks]
3. Expansions: SMPS (Switched Mode Power Supply), BIOS (Basic Input Output System), GUI (Graphical User Interface), SSD (Solid State Drive), ALU (Arithmetic Logic Unit). [10 Marks]
4. True/False: 1-F, 2-T, 3-F, 4-T, 5-T. [10 Marks]

## Section B Solutions [40 Marks]
