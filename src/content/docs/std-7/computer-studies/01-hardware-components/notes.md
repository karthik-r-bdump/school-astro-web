# Chapter 1: Hardware Components

## 🎯 Syllabus Scope & Objectives
- Definition of hardware.
- Internal: Motherboard, CPU (ALU, CU, Registers), SMPS, RAM, ROM.
- External: Input devices, Output devices, Storage devices (HDD, SSD).
- Units of memory: Bit, Byte, KB, MB, GB, TB.

---

## 📖 Key Concepts & Detailed Notes
### 1. Internal Hardware Architecture
- **Motherboard**: Central circuit board connecting CPU, RAM, and expansion slots.
- **CPU Units**:
  - ALU: Arithmetic and logic operations.
  - CU: Coordinates instruction execution.
  - Registers: Fast temporary storage cells.
- **SMPS**: Switched Mode Power Supply converts AC to DC voltages ($+3.3V, +5V, +12V$).
- **RAM vs ROM**: RAM is volatile, read/write; ROM is non-volatile, read-only containing BIOS.
